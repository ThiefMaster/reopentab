# ReOpenTab

Some time ago, Firefox devs make the odd decision to change the CTRL-SHIFT-T shortcut to reopen the
last closed tab, window, etc. from any window, not just the last closed tab from the current window.

Apparently this was done to cater for (former) Chrome users, but as a power user this absolutely
sucks, especially when working with multiple screens and one window on each screen. Having random
crap from the other window show up there is annoying!

## Installation

- Install the extension
- Go to `about:keyboard`, and unbind (or change) the default CTRL-SHIFT-T shortcut; it's assigned to
  "History / Reopen Last Closed Tab" by default.
- Enjoy your keyboard shortcut being useful again :)
